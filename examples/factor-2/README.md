# Factor 2: Explicit Tool Contract

## How to Run

```bash
python solution/tools.py
```

> This Factor does not directly call an LLM. It mainly demonstrates tool interface design, parameter validation, and idempotency.

## Files

- `starter/tools.py`: Skeleton code with TODOs.
- `solution/tools.py`: Reference implementation of write_file and calculator with validation, blocklist, and idempotency.
